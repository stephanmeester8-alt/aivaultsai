2. TASK 01 — Customer Zero Orchestrator

  • Vastgesteld: alle onderdelen bestonden (chat, conversations, intent, lead repository, booking, migratie) maar er was nog geen centrale orchestrator.
  • Aangemaakt: apps/web/lib/customer-zero/orchestrator.ts (eerste versie 1702 bytes) en de testroute apps/web/app/api/customer-zero/test-orchestrator/route.ts (maakt eerst een echte conversations-rij aan, roept daarna de orchestrator aan, retourneert JSON; fouten non-fataal als {ok:false}/500).
  • Gevonden databasefout: NeonDbError: ... violates foreign key constraint "leads_conversation_id_fkey" — de test gebruikte crypto.randomUUID() zonder die conversation aan te maken. Fix: alleen de testroute aanpassen (eerst conversation inserten); niet de orchestrator/database/API wijzigen.
  • Testprocedure: npm run dev (localhost:3000) + Invoke-RestMethod -Method POST -Uri "http://localhost:3000/api/customer-zero/test-orchestrator".
  • Relatie met huidige repo: deze testroute is de ongetrackte map apps/web/app/api/customer-zero/test-orchestrator/; de orchestrator kreeg later dependency injection (commit eec0e6e).

3. Commercieel funnel-ontwerp

Bezoeker → AI-assistent → (informatief: antwoord | commercieel: intent herkennen)
→ Interesse / Lead / Hoge intent → Lead kwalificeren → PostgreSQL/Neon
→ "Wil je een kennismaking?" → Ja → Availability → Afspraak boeken → PostgreSQL

Leadvelden om meetbaar te maken: source, session_id, company, email, commercial_intent, intent_score, qualification_status, requested_service, conversation_summary, appointment_status, created_at. Doel-funnel: 100 bezoekers → 32 gesprekken → 14 intents → 8 leads → 5 afspraken → 2 klanten.

5. Werkwijze & praktijk

  • Protocol: 1 taak → bouwen → testen → controleren → commit → pushen; geen subtaken; volledige bestanden aanleveren i.p.v. diff-fragmenten; eerst oorzaak bewijzen, dan fixen; geen tool-credits veronderstellen (Cursor was op).
  • Omgeving: .ts-bestanden openen in de editor (niet uitvoeren); PowerShell niet "bevroren" houden midden in diff-output; artefacten als ai-newappsweb/ai-new opruimen; e-mails in node_modules zijn package-metadata, geen klanten; lokale API-tests vereisen een draaiende npm run dev.
